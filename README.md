# MinutesFlow Pro

A professional meeting minutes generator built using Streamlit.

## Features

- Dynamic attendee management
- Agenda item generation
- Action item tracking
- Markdown export
- PDF export
- Professional UI

## Installation

```bash
pip install -r requirements.txt
```

## Run Locally

```bash
streamlit run app.py
```

## Deployment

Recommended deployment:

- Streamlit Community Cloud
- Render
